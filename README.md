# theHunterWiki - Overwolf App

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Overwolf-red.svg)


theHunterWiki is an overwolf extension for the game **theHunter: Call of the Wild** that let users check an in-game wiki without the need to go into the browser. 

## Functionality

* **Multiple Maps:** Support for all the availables 16 maps (Every map has its own page)
* **Animals Details:**
    * **Need Zones**: Time and type of the need zones divided by map.
    * **Trophies:** Minimum ratings for the animals and if a great-one trophy is available
    * **Max Difficulty:** Maximum available difficulty for the animals
    * **Fur Types:** A complete list of all the possible fur/plumange, with rarity and sex-distingued.
* **Fast Research:** A search bar to fast reasearch an animal without
* **Minimal UI:** To make the User Experience fast during the hunt

## Contribution
Contributions are welcome, the app will be updated as soon a dlc comes and data are available, if you want to contribute make sure to read the [CONTRIBUTING.md](CONTRIBUTING.md) before you send a PR.

Here's how the process works:

1.  Fork the project
2.  Create your feature branch (`git checkout -b feature/NewFunction`)
3.  Commit the changes (`git commit -m 'Added something...'`)
4.  Push the changes (`git push origin feature/NewFunction`)
5.  Open a pull request

After that wait for a maintainer to give further instruction. Before sending a PR remember to test your app on Overwolf. To test on overwolf you need to be a *whitelited developer*. Check documentation for further informations.
